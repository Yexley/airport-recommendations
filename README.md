<a name="getting-started"></a>

## 使用指南

1. **先看结算页的计费规则。** 周期套餐要核对流量重置频率，一次性包要核对总量和有效期。如果注册页没有自动填入邀请码，可对照各节首行。网际快车使用专属邀请地址。
2. **用一台常用设备完成配置。** MESL 可用服务商应用登录。使用第三方客户端时，先对照服务商说明确认系统和协议版本，再从自己的账户导入订阅。订阅地址是个人连接凭据，请妥善保管。[MESL 服务条款](https://tos.meslcloud.com/terms?lang=zh)
3. **用日常任务验证。** 在平时使用的时段和网络上操作一遍。如果你的工作依赖 ChatGPT、Claude 或 Gemini，就打开对应产品并执行日常操作。如果主要看 YouTube 或 Netflix，就播放目标内容并观察一段时间，再按实际体验选套餐。
